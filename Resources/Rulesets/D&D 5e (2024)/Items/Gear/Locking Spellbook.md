# Locking Spellbook

This 100-page leather-bound tome can be used as a Spellbook. It is closed with a lock that comes with a key. As a [[Actions#Utilize|Utilize]] action, a creature can try to pick the lock using [[Thieves' Tools]], doing so with a successful DC 15 Dexterity ([[Skills#Sleight of Hand|Sleight Of Hand]]) check.
