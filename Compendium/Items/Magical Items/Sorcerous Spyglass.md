# Sorcerous Spyglass

This elegant brass [[Spyglass]] features an intricate lens mechanism. A creature looking through the sorcerous spyglass has advantage on Wisdom ([[Skills#Perception|Perception]]) checks to detect things that can be seen. In addition, the user can view magical auras while looking through the spyglass, as if under the effect of a [[Detect Magic]] spell.
